# Bygdebladet Lokalhandball

Eit nynorsk kampsenter for lokalhandball med resultat, kommande kampar og offisielle tabellar.

## Kampdetaljar

Kampdialogen har tre faner: Rapport, Tabell og Lag. Rapporten byggjer på registrerte kampdata frå NHF. Spelarstatistikken blir vist når NHF publiserer spelarlistene. For kampar med berre lagstatistikk blir den viste i Lag-fana.

Kampbilde blir sende til [Lokalhandball-skjemaet i Tally](https://tally.so/r/RWMgXj). Lenka frå kampdialogen legg ved kamp-ID, lagnamn og kampdato. Innsendingane ligg i Tally for redaksjonell vurdering.
